# Changelog

Android preview and desktop Python versions are separate. The latest Android
Preview is `1.5.0` (version code 8).

## Android 1.5.0 (2026-10-15)

- Replace the permanent bubble adjuster with pinch resizing and configurable
  gestures; allow smaller visible sizes with an accessible touch target.
- Default to Light appearance and retain Dark/System choices.
- Add microphone-level feedback and a visible transcription state.
- Process completed Parakeet phrases during recording and report timing stages.
- Preserve text through clipboard fallback when insertion fails or is uncertain.
- Import personal Wispr Flow words and corrections through a read-only Windows
  export helper and Android preview/confirmation flow.
